# K8s 出站禁网的真集群实测结论（issue #418）

## 一句话结论

在 **kind v0.24.0 / Kubernetes v1.31.0 / Calico v3.30.3** 这台真实集群上，本仓 K8s
Job 后端的「Egress=denied 档」四条验收标准**逐条兑现**：禁网作业的出站尝试**确实被
数据面拦下**（探针 exit 0 + 业务容器打印 EGRESS_BLOCKED），且**同一条探针命令在没有
策略的对照 Pod 上连得上**（exit 1 + EGRESS_OPEN）——结论不是「探针压根不通」冒充的。

## 这次测的是什么

`#262` 交付了机制面（声明面门禁 + 独立执行命名空间 + 严格策略装配 + init 容器探测），
但**「机制齐备」≠「机制在真集群上被验过」**：apiserver 接受 NetworkPolicy ≠ 数据面生效
（取决于集群的 CNI 是否实现 NetworkPolicy）。`#418` 要的就是那次真机结论。

## 四条验收标准 → 实测

| # | 验收标准 | 实测 | 判定 |
|---|---|---|---|
| 1 | 装配禁网作业（Egress=denied） | 作业创建成功；策略创建后读回校验通过（落库形态就是本作业的 Egress 全拒策略） | ✅ |
| 2 | init 容器访问外部地址**必须失败** | 探测容器退出码 0（实测面 `egress_verified=probe_exit_0`）⇒ 出站尝试失败 | ✅ |
| 3 | 业务容器正常跑完 | `res.OK=true`，业务容器 stdout = `EGRESS_BLOCKED` | ✅ |
| 4 | 再叠加一条「允许出站」策略 ⇒ **创建即被拒** | 返回 `ErrNetworkPolicy`（叠加语义对账生效，作业根本没创建） | ✅ |

两行并读就是这次结论的全部：

- 对照侧 `EGRESS_OPEN` + 退出码 1 ⇒ **同一条命令在无策略时确实连得上**（探针不是哑的）；
- 禁网侧 `wget: download timed out` + `EGRESS_BLOCKED` + 退出码 0（`probe_exit_0`）
  ⇒ **出站被数据面拦下**，且拦的是 TCP 连接本身（超时，不是「拒绝」），
  正是 NetworkPolicy 丢包（而非 RST）的形态。

## 判据为什么可信：**阳性对照**

「探测失败」有两种互不可区分的成因：**被策略拦下** 与 **探针压根不通**。只断言前者，
禁网没生效时用例照样绿（假绿）。本轮把判据改成**同一条命令、两个方向都断言**：

| 侧 | 有无禁网策略 | 实测 |
|---|---|---|
| 对照 Pod | 无 | 退出码 **1** + stdout `EGRESS_OPEN` ⇒ 出站**可达** |
| 禁网作业 | 有（Egress 全拒） | 退出码 **0**（= `probe_exit_0`）+ stdout `EGRESS_BLOCKED` ⇒ 出站**被拦** |

同一条脚本、同一个目标（集群内见证端点的数字 IP），**唯一的变量是那张 NetworkPolicy**
⇒「被拦」这件事不可被「探针不通」冒充。

两个配套口径：

- 目标用**数字 IP**（见证端点的 Pod IP）而不是域名：域名解析本身也是出站，被拦时失败落在
  DNS 层 ⇒「连不上」与「解析不了」分不开，两种失败不可区分；
- 目标用**集群内见证端点**而不是公网地址：见证端点由用例自己起、自己判活，
  结论不依赖公网可达性（公网可达性会让这条验收变成「网络一抖就红」）。

## 结论边界（明确**没有**被证明的部分）

1. 证明的是「**机制在这台集群的 CNI 上兑现**」——CNI 是 Calico v3.30.3。别的 CNI
   （kube-router / Cilium 等）未测；但判据与 CNI 无关（本后端只做三件事：读 CNI 能力事实、
   装策略、跑探测）。
2. 本次取证的是**集群内网**这一层的出站被拦。策略形态是 `policyTypes: [Egress]` +
   **空 egress 列表**（K8s 语义 = 拒绝一切出站，不分目的地）⇒「到公网的出站同样被拦」
   由同一条策略覆盖，但**本次未对公网地址单独取证**。
3. 这是**一次性真机结论**，不是持续门禁：CI 不跑这条（起集群 + 装 Calico 要拉镜像，
   抖动会连带把别的门禁染红）；可复跑入口是 `make k8s-e2e`。
4. 宿主必须注入**CNI 能力事实**与**探测镜像**（`K8sCNICapability` / `K8sEgressProbe`）——
   这是契约；没注入时声明面降级为 `EgressUnrestricted`（fail-closed），不静默宣称禁网。

## 顺带暴露的两个真 bug（都已修）

1. **叠加策略的 JSON 载荷多一个引号**（`},"` ⇒ 载荷非法）——这条路径此前**从未在真集群上
   执行过**（CI 里它显式 Skipf）⇒ 判据代码「存在但从未被执行」也是一种假绿。
2. **kubeconfig 的 context 与端口会漂**：`kubectl config view` 取的是**第一个** cluster，
   不是当前 context 的 ⇒ 脚本会把凭据发到**别的集群**去（当时打到 10.10.30.31 ⇒ 401）。
   正确口径：`kubectl config view --minify`（只取当前 context）+ `kind export kubeconfig` 刷新。
